# AI Assistant Instructions for Carapace Project

**READ THIS FIRST when working on this project!**

## 🎯 Critical Rules

### Script Location (MANDATORY)

**⚠️ ALL SCRIPTS MUST BE IN `tooling/<category>/src/` AS NPM PACKAGES**

```
✅ CORRECT:
tooling/dev/src/cleanup-ports.sh
tooling/blockchain/src/create-pool.ts
tooling/testing/src/e2e-blockchain-test.ts

❌ WRONG:
scripts/cleanup-ports.sh
tooling/scripts/cleanup-ports.sh
tooling/blockchain/create-pool.ts  (missing src/)
apps/web/scripts/test.sh
packages/sdk/scripts/build.sh
```

## 🔨 Common Tasks

### Before You Create a Script

1. Check if it already exists: `ls -R tooling/scripts/`
2. Determine the category (dev/blockchain/sui/testing/docs/demo)
3. Place it in the correct subdirectory
4. Update `tooling/README.md` with documentation
5. Add to `Taskfile.yml` if it's a common operation

### When You Need to Run a Script

1. Look in `tooling/scripts/<category>/`
2. Check `tooling/README.md` for usage
3. Check `Taskfile.yml` for Task integration
4. Use `task <command>` if available, otherwise run directly

### Common Operations

```bash
# Clean up development ports
task dev:cleanup

# Start development services
task dev

# Run blockchain script
bun run tooling/scripts/blockchain/create-pool.ts

# Run tests
task test:e2e
```

## 🔑 Port Allocation

All ports are in the 3600-3699 range:

| Port | Service | Notes |
|------|---------|-------|
| 3600 | API (Express) | Carapace API |
| 3601 | Web (Next.js) | Frontend application |
| 3602 | PostgreSQL | Docker (mapped from 5432) |
| 3603 | Redis | Docker (mapped from 6379) |
| 3604 | Grafana | Docker (mapped from 3000) |
| 3605 | Prometheus | Docker (mapped from 9090) |
| 3606 | x402 Facilitator | HTTP 402 payment facilitator |
| 3610 | Sui Localnet | Sui RPC endpoint |
| 3611 | Sui Faucet | Sui faucet endpoint |

## 🚦 Development Workflow

1. **Clean up ports** (if needed): `task dev:cleanup`
2. **Start infrastructure**: `task docker:up`
3. **Start Sui** (separate terminal): `sui start --force-regenesis`
4. **Start dev servers**: `task dev` or individually with `task dev:web`, `task dev:api`

## 📝 Adding New Features

### Adding a New Script

1. Place in `tooling/<category>/src/script-name.ts`
2. Make executable if shell script: `chmod +x script-name.sh`
3. Add to `tooling/<category>/package.json` scripts:
   ```json
   {
     "scripts": {
       "my-script": "bun run src/script-name.ts"
     }
   }
   ```
4. Document in `tooling/README.md`
5. Add to `Taskfile.yml` if common:
   ```yaml
   category:action:
     desc: Description
     cmds:
       - bun run ./tooling/<category>/src/script-name.ts
   ```

### Adding a New Task

1. Add to `Taskfile.yml` under appropriate section
2. Follow naming convention: `category:action` (e.g., `dev:cleanup`, `pool:create`)
3. Add description with `desc:` field
4. Document in this file if it's commonly used

## 🔍 Troubleshooting

### Port Already in Use

Run the cleanup script:
```bash
task dev:cleanup
# or directly:
./tooling/scripts/dev/cleanup-ports.sh
```

### Script Not Found

1. Check `tooling/scripts/` and subdirectories
2. Check `tooling/README.md` for documentation
3. Search: `find tooling/scripts/ -name "*keyword*"`

### Task Not Found

1. List all tasks: `task --list`
2. Check `Taskfile.yml`
3. Create the task if it doesn't exist
