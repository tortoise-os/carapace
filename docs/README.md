## Maintenance

### Adding New Documentation

1. Place document in appropriate directory
2. Add entry to [INDEX.md](./INDEX.md)
3. Include metadata header (see below)
4. Link from relevant documents

### Metadata Header Format

```markdown
---
title: Document Title
created: YYYY-MM-DD
updated: YYYY-MM-DD
status: active | review | deprecated | archived
category: guide | research | planning | status | security
author: Team Name
---
```

### Review Schedule

- **Weekly**: Planning and task documents
- **Monthly**: Guides and how-to docs
- **Quarterly**: Research and status reports
